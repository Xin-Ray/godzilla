# Godzilla — City-Scale MR (Quest 3)

Unity 6000.2.15f1 · Meta XR Core SDK 85 + MRUK 85 · OpenXR · URP.

A giant humanoid (30–200 m) stands in the real city outside your window in passthrough; you drive it with Touch controllers.

- Design: `docs/superpowers/specs/2026-10-28-city-scale-mr-design.md`
- Plan: `docs/superpowers/plans/2026-10-28-city-scale-mr-mvp.md`
- Validation: `docs/validation/`

## Commands
```
tools\run_tests.ps1 -Platform EditMode     # unit tests
tools\run_tests.ps1 -Platform PlayMode     # scene tests (editor sim room)
tools\build_quest.ps1                      # Builds\Godzilla.apk
tools\wifi_adb.ps1                         # one-time wireless adb bootstrap
tools\deploy_quest.ps1 -Serial <ip>:5555   # install + launch + filtered logcat
```
The scene `Assets/Scenes/City.unity` is generated by `ProjectBootstrap.Run` (Editor menu `Godzilla/Bootstrap Scene`, or `-executeMethod Godzilla.Editor.ProjectBootstrap.Run`).
