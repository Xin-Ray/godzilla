# City-Scale MR Fighting MVP 0.1 / 0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Quest 3 passthrough app where a 30–200 m humanoid stands in the real city outside the user's window (correct parallax + window occlusion, position persisted), and the user drives it with Touch controllers (walk/run/turn/jump/punch/kick/roar).

**Architecture:** True-scale Unity world (1 unit = 1 m). MRUK room anchors give the window frame; an EffectMesh depth-only occluder with window holes hides everything but the window view. A `CityFrame` (origin at the window, forward = outward normal) maps saved placement parameters to world space. Locomotion is programmatic (no root motion) with speeds scaled by character height and a global animation time scale; the Animator only drives pose.

**Tech Stack:** Unity 6000.2.15f1, URP 17.2.0, Meta XR Core SDK 85 + MRUK 85 (via `com.meta.xr.mrutilitykit`), OpenXR 1.14.3 + Meta OpenXR 2.1.0, AR Foundation 6.1.1, Input System 1.16.0, Unity Test Framework, Mixamo Humanoid assets.

**Spec:** `docs/superpowers/specs/2026-10-28-city-scale-mr-design.md`

## Review Focus

1. Room scanned but no `WINDOW_FRAME` and head ray hits no wall (user faces a doorway) → must still land in HeadFrame fallback, never a null reference. Test in Task 3 (`WindowCalibrationLogicTests.NoWindow_NoWallHit_UsesHeadFrame`).
2. Saved placement whose anchor UUID no longer exists in the room → enter Placement with defaults, keep the old file untouched until a new save. Test in Task 2 (`PlacementStoreTests.LoadMismatchedUuid_ReturnsNeedsPlacement`).
3. Height slider pushed past 200 m or below 30 m from the DevPanel or stick → clamp, never a 0-scale or negative-scale character. Test in Task 5 (`PlacementLogicTests.Height_Clamped_30_200`).
4. Attack button mashed during a jump or during another attack → no re-trigger, locomotion lock released exactly once. Test in Task 10 (`GiantAnimLogicTests.Attack_WhileLocked_Ignored`, `Lock_ReleasedOnce`).
5. Stick drift (|axis| < 0.15) → character must not creep. Test in Task 11 (`GiantMoverTests.Deadzone_NoMotion`).
